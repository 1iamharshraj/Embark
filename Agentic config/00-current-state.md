# Current state of the platform

> Updated 2026-08-08 after Phase 7 final QA.

## 1. What Embark India is

A web platform aimed at **Tier‑2 MBA students** in India. Brand voice: sharp, confident, mentor-like. Tagline theme: *“start before you feel ready.”*

Live domain (legacy): `embarkindia.in` (Hostinger shared hosting, still serving the old static site). New app: `web/` Next.js 14 rebuild, ready for Vercel deployment.

## 2. How it is built now

The new application is in `web/`:

- **Framework:** Next.js 14 App Router.
- **Database:** PostgreSQL via Prisma ORM (currently local Docker; production target: Neon).
- **Auth:** NextAuth.js v4 with credentials provider and JWT session.
- **Payments:** Razorpay test mode (orders, verify endpoint, test-mode signature bypass).
- **PWA:** `next-pwa` with `manifest.json`, service worker, icons, and offline page.
- **Admin:** Protected `/admin` routes and `/api/admin/*` API namespace.
- **Storage:** Local upload handler (`app/api/uploads/[...path]`) — production should switch to S3/R2 or Supabase Storage.
- **Old static site:** HTML/CSS/JS files remain at the repo root as the live archive until DNS is cut over to Vercel.

## 5. Security posture

- Admin APIs require authenticated admin session (`isAdmin: true`).
- `/account` redirects unauthenticated users to `/login`.
- `/admin` redirects non-admin users to `/account`.
- `/api/dev/reset-tokens` is guarded by `process.env.NODE_ENV === "development"` and returns 404 otherwise.
- Passwords are hashed with bcrypt; reset tokens are single-use and expire in 1 hour.

## 6. Known blockers before public launch

1. **Payments:** Razorpay is in test mode. Replace with production keys.
2. **Email:** Reset-password links are logged to the console. Integrate a real email provider.
3. **File storage:** Local uploads. Move to S3/R2/Supabase Storage for production.
4. **Database hosting:** Move from local Docker to Neon (or equivalent managed PostgreSQL).
5. **Hosting / DNS:** Deploy to Vercel and cut over DNS from Hostinger.
6. **Old static site:** Keep at repo root until production DNS switch is verified; then move to `archive/`.
7. **Dependencies:** `npm audit` reports 10 high-severity issues in build-time/framework packages (Next.js 14, eslint-config-next, next-pwa/workbox). Schedule a post-launch dependency upgrade sweep.
